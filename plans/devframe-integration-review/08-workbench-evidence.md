# Slice 08 workbench evidence

Status: partial. The standalone workbench offers an explicitly enabled, source-and-actor capability-gated inspection tab for state, DOM, Vue components and automated accessibility findings. `inspection.enabled` opts in to generic inspection; component and accessibility capabilities require their separate opt-ins. A source-granted loading placeholder retains tab navigation while the selected actor loads; actions require the exact current actor and source grant. On withdrawal or disconnect the contribution is removed. Colliding user plugin IDs prevent internal registration without replacing the user plugin.

The canvas Pick element tool inspects the exact selected admitted frame, converts viewport coordinates to document CSS pixels, fills the selector and reads the picked DOM. It does not silently select, mount or inspect a nonselected frame. The panel offers an owned highlight lease and exact-lease clearing; its scope cleanup clears the owned highlight. State, DOM, component details and audit results retire on owner or capability changes; failures retain usable prior results. Keyboard users can enter a selector and submit with Enter. Existing authorized `SourceDrawer` opens the story in an editor; no component source-location navigation is exposed because no validated server mapping/editor action exists for it. Axe findings do not claim accessible names where the engine cannot provide them.

## Detached report implementation

`createInspectionReport` in `packages/histoire-devframe/src/report/index.ts` explicitly accepts up to 32 validated variant/DOM inspection results and returns versioned detached JSON plus standalone HTML. Default output contains timestamps, mode, truncation, bounded counts, and SHA-256 fingerprints of owner fields; it does not copy runtime values, DOM content, raw IDs or transport credentials. Fingerprints are not encryption: low-entropy identifiers can be guessed.

Callers can explicitly select individual state fields and DOM nodes per result, and must supply a sanitizer for each selected value. Only selected state values and DOM text, bounded structural tags and parent indexes are retained; attributes and selectors are omitted. Sanitizer input and output are validated and cloned, selected content is size-bounded, and HTML escapes it. **Sanitization is caller-owned and cannot guarantee arbitrary secrets are removed. Selected state field names are retained verbatim; callers must choose safe names and recursively sanitize nested values.** HTML labels content as historical and warns about sensitivity, uses restrictive CSP, and contains no scripts, links, forms, network resources or live commands. The caller owns any filesystem write; nothing exports automatically.
