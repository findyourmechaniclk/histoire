# 01 — Contracts, versioning and optional boundaries

Depends on 00. Goal: adapt bounded inspection types and capability negotiation without changing established wire behavior or activating any unimplemented service.

## Likely paths

`packages/histoire-protocol/src/{types,bridge,inspection,index.ts}`; `packages/histoire-shared/src/types/config*.ts`; `packages/histoire/src/node/config/` and `virtual/embed/descriptor.ts`; SDK import boundaries; new `packages/histoire-devframe/{package.json,src/client/index.ts,src/node/index.ts,src/types.ts}` only when justified by compatibility review. Reuse candidate `inspection/{capabilities,validation,extensions,rows,debug-buffer}.ts` and frozen reader as candidates, not wholesale replacements.

## Work

1. Freeze current descriptor/snapshot, error envelopes, capability names and old reader behavior from main and real fixtures. Capture the complete applicable `HistoireBridgeIdentity`: protocol version, session ID, connection ID, mount ID, source ID, epoch, revision, runtime/document ID and target. Capture `selectionVersion` for selection-bound work so leaving and returning to the same target creates a new lifetime; an explicitly targeted surviving document must not be invalidated solely by an unrelated selection change. Mount and runtime are independent, not alternatives. Map the private captured identity explicitly to project, authenticated peer and attachment ownership at the broker; publish only the bounded identity fields needed by the public result. Preserve existing validation on requests, replies and cancellation rather than minting replacement authority.
2. Define detached JSON DTOs for live variant, bounded DOM, highlight and diagnostic pages, with validated inputs, owner, mode and explicit truncation. Separate isolated ARIA structure from actual accessibility audit; reserve component/audit capability until slice 07 works. Map capability names to operation names explicitly.
3. Preserve version-1 extension behavior: current descriptor and snapshot readers tolerate unknown top-level fields within their complete wire budgets, while existing capability maps and nested policy/config objects remain strict. Do not introduce new keys inside those strict maps. Strictly validate recognized inspection extensions and finite commands, reject unknown command arguments, malformed data and oversized values, and keep tolerated top-level fields bounded. Bound input and *complete serialized result* including identity and envelope. Ensure projection never invokes getters, handles cycles and restricted values, and produces stable bounded omissions. Reuse current serializer/validation utilities rather than parallel implementations.
4. Add opt-in source config and descriptor metadata with default disabled; derive effective availability from actual source/runtime implementation and origin policy. Existing readers must accept new optional fields; new readers must accept old absent fields without granting authority. Ensure static descriptors do not promise a backend.
5. Establish browser-safe vs Node exports. Browser SDK/protocol remain independent of adapter and Node dependencies; public adapter entry should have no side effects at import. Confirm required peer dependencies and only advertise a feature where installed, tested and authorized. Re-evaluate historical Devframe compatibility with exact chosen versions.

## Tests and gate

Add public wire tests using a frozen current reader for old-reader/new-descriptor and snapshot, and the new reader for old descriptors and snapshots. Verify bounded unknown top-level extensions remain compatible, oversized extensions fail, strict nested capability/policy fields and unknown command arguments fail, and recognized malformed inspection fields fail. Test limits, cyclic/getter inputs, absent capability and actual origin-policy intersection. Exercise exact request/reply/cancellation identity across reconnect, mount or runtime replacement and repeated same-target selection, plus an explicitly targeted surviving document across unrelated selection changes. Run protocol suite and SDK baseline. Test browser bundle graph and Node import without DOM/Devframe; packed proof repeats in 09. A DTO or type alone must not expose a reachable operation. Record any compatibility break and block until resolved, rather than silently versioning away existing clients.
